## 1. 引言

### 1.1 编写目的

本文档旨在明确“Kylin系统下待办软件”的功能需求与非功能需求，为后续的系统设计、编码实现和测试提供基准，确保开发方向与预期目标一致。

### 1.2 项目背景

随着国产操作系统的普及，银河麒麟（Kylin）系统的应用生态正在逐步完善。目前市面上缺乏轻量、现代且专为 Linux 桌面环境优化的待办事项管理工具。本项目旨在填补这一空白，提供一款简洁高效的跨平台桌面应用。

### 1.3 项目范围

* **包含**：日历视图（日，周，月），支持农历，节假日显示；待办事项的增删改查、状态标记、重要性标记；本地数据持久化；Kylin 系统原生安装包生成。
* **不包含（V1.0）**：云端数据同步、多用户协作、移动端适配。

---

## 2. 总体描述

### 2.1 用户特征

* **目标用户**：使用银河麒麟操作系统的办公人员。
* **使用场景**：查看节假日、日常工作任务记录、办公计划管理、临时备忘。

### 2.2 运行环境

* **开发环境**：Windows 10/11 + IntelliJ IDEA + JDK 17/21。
* **目标运行环境**：银河麒麟桌面操作系统 V10 (基于 Linux，UKUI 桌面环境)，支持 x86_64 和 ARM64 架构。

### 2.3 技术栈约束

* **开发语言**：Kotlin，JavaScript
* **UI 框架**：Compose Multiplatform (Desktop)
* **构建工具**：Gradle
* **数据存储**：SQLite

## 3. 功能需求 (Functional Requirements)

### 3.1 核心功能清单

| 编号 | 功能名称   | 优先级  | 描述                                         |
| ---- | ---------- | ------- |:-------------------------------------------|
| F-01 | 日历视图   | 高(P0)  | 主界面显示日历视图，包含农历信息，显示中国大陆所有节假日(包括调休)。        |
| F-02 | 添加待办   | 高 (P0) | 用户可通过输入框输入文本，双击日历添加一条新待办。                  |
| F-03 | 查看列表   | 高 (P0) | 主界面以月视图显示日历视图，日节点显示当天待办。                   |
| F-04 | 标记完成   | 高 (P0) | 用户可点击复选框切换待办事项的“完成/未完成”状态，UI 需有视觉反馈（如删除线）。 |
| F-05 | 删除待办   | 高 (P0) | 用户可点击删除按钮移除指定的待办事项。                        |
| F-06 | 数据持久化 | 高 (P0) | 软件关闭后，数据自动保存至本地；再次打开时自动加载历史数据。             |

### 3.2 详细用例说明 (以“添加待办”为例)

* **前置条件**：软件已正常启动。
* **基本流程**：
    1. 用户双击日节点可以新增待办事项。
    2. 用户双击后弹出待办列表（无事项则为空），双击空白处可添加新待办事项。
    3. 事项可指定优先级等功能。
    4. 判断用户是否输入内容，为空则不能保存，并提示；不为空则按日保存到数据库。
* **异常流程**：
    1. 用户输入为空或纯空格。
    2. 系统不执行添加操作，“添加”按钮保持禁用状态或给出提示。

## 4. 非功能需求 (Non-Functional Requirements)

### 4.1 兼容性与适配 (关键)

* **跨平台 UI 一致性**：在 Windows 和 Kylin 系统下，UI 布局和渲染效果必须保持一致。
* **Linux 输入法支持**：在 Kylin 系统下，必须能正常呼出 Fcitx/IBus 中文输入法进行输入。
* **字体渲染**：在 Linux 环境下，需解决 Java/Compose 默认的字体发虚问题，确保中文显示清晰。

### 4.2 性能需求

* **启动速度**：冷启动时间不超过 2 秒。
* **响应时间**：添加、删除、勾选等操作的 UI 响应延迟不超过 100 毫秒。

### 4.3 用户体验 (UX/UI)

* **界面风格**：采用 Material 3 设计规范，主色调建议适配 Kylin 系统的“麒麟蓝”。
* **操作简便**：支持键盘快捷键（如 Enter 添加，Delete 删除）。

---

## 5. 数据需求

### 5.1 数据模型

* **实体**：待办事项 (TodoItem)
* **属性**：
    * `id` (String): 唯一标识符 (UUID)
    * `text` (String): 待办内容
    * `isCompleted` (Boolean): 完成状态 (默认 false)
    * `createdAt` (Long): 创建时间戳 (可选，用于后续排序)

### 5.2 存储方案

* **存储介质**：SQLite 数据库。

## 6. 验收标准 (Acceptance Criteria)

1. 软件能在 Windows 环境下正常编译、运行，且所有核心功能（F-01 到 F-06）测试通过。
2. 能够通过 Gradle 成功打包生成 `.deb` 格式的安装包。
3. 在银河麒麟 V10 虚拟机或物理机上，成功安装 `.deb` 包。
4. 在麒麟系统上运行时，界面显示正常，中文输入法可正常使用，数据能够正常保存和读取。
