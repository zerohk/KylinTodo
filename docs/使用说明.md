# 大智日历 · 使用说明

面向使用者的操作手册。安装包请从
[GitHub Releases](https://github.com/zerohk/KylinTodo/releases) 下载。

---

## 一、安装

### 银河麒麟 V10（.deb）

```bash
sudo dpkg -i dazhi-calendar_1.1.7_amd64.deb
sudo apt-get install -f          # 补齐依赖
```

安装后可在开始菜单的「实用工具」里找到「大智日历」。

> **从 1.0.0 升级**：1.0.0 的包名是 `kylintodo`，之后的版本改为
> `dazhi-calendar`，系统不视为升级。需先卸载旧包：
> `sudo dpkg -r kylintodo`

> **数据不会丢失**：待办数据存放在 `~/.local/share/KylinTodo/`，
> 卸载与重装都不会删除，重装后自动读回。

### Windows（.msi）

双击 `dazhi-calendar-1.1.7.msi` 按提示安装即可。无需另装 Java
（安装包已内含运行时）。

## 三、日历操作

### 基本操作

| 操作 | 效果 |
| --- | --- |
| **单击**某一天 | 选中该日期，右侧面板显示它的待办 |
| **双击**某一天 | 打开「日期详情」窗口（含该日与本周其余安排） |
| 点格子右上角 **`＋`** | 直接为该日期添加待办 |

### 日期格子上显示什么

- **左上角**：日期数字。法定节假日显示红色「休」角标；调休上班日显示绿色「班」角标
- **右上角**：`＋` 按钮，点击直接为这天添加待办
- **右下角**：农历日期；若当天是节气则显示节气名（如「寒露」）
- **日期下方**：该日待办数量角标，颜色对应当天**最高优先级**的待办

### 三种视图

- **月视图**：固定 6 行 × 7 列共 42 天，从周一开始
- **周视图**：显示所在自然周的 7 天
- **日视图**：显示所在周的 7 天，选中日高亮

> 三种视图的行高与网格一致，切换时不会有布局跳动。

## 四、待办操作

### 添加

三种方式，任选其一：

1. 点日历格子右上角的 **`＋`**
2. 点右侧待办面板标题栏的 **`＋`**
3. 双击某天打开详情窗口后，**双击窗口空白处**（或点窗口右上角 `＋`）

弹窗中可设置：

- **内容**（必填，纯空格不允许保存）
- **重要程度**：无 / 低 / 中 / 高
- **标签**：自由输入，回车确认，最多 6 个

### 完成 / 取消完成

点待办左侧的**复选框**。完成后文字会显示删除线。

### 删除

点待办行右侧的**垃圾桶图标** —— **会先弹出确认框**，避免误删。

### 多选批量操作

点待办面板标题栏的 **`☑`** 图标进入多选模式：

- 点击整行即可选中（选中行会高亮）
- 顶部操作栏提供：**全选 / 完成 / 取消完成 / 删除**
- 再次点 `☑`（此时显示为 `✕`）退出多选

> 删除同样会先弹出确认框，并显示将删除多少条。

### 搜索

点工具栏右侧的 **`搜索`** 按钮，支持三类条件（可组合，需**同时满足**）：

| 条件 | 说明 |
| --- | --- |
| **关键词** | 文本包含匹配，不区分大小写。搜「牛奶」能找到「买牛奶」 |
| **标签** | 可多选，需包含所选的全部标签 |
| **优先级** | 单选，再点一次取消 |

搜索结果里可以：

- 点**复选框**直接标记完成
- **点击整行**跳转到该待办所在的日期

## 五、桌面小窗

一个常驻桌面的小窗口，显示当天的待办。

### 打开与关闭

- 工具栏点 **`桌面小窗`**
- 或 设置 → 启动行为 → 勾选「启动时打开桌面小窗」

### 小窗操作

| 位置 | 操作 |
| --- | --- |
| **标题栏**（按住拖动） | 移动小窗位置 |
| **★ 星形图标** | 切换「始终置顶」。置顶时显示为主色 |
| **↗ 图标** | 打开主窗口 |
| **✕ 图标** | 关闭小窗 |
| 列表内复选框 | 标记完成 |
| 列表内垃圾桶 | 删除（有确认框） |
| 底部「添加」 | 为该日添加待办 |

## 六、设置详解

点工具栏的 `⚙` 打开设置。

### 外观

| 选项 | 说明 |
| --- | --- |
| **应用名称** | 同时用于界面左上角与窗口标题，留空恢复默认 |
| **皮肤** | 跟随系统 / 浅色 / 深色 |
| **字体大小** | 小 / 标准 / 大 / 特大 |
| **自定义背景颜色** | 6 种预设纯色，点「默认」恢复跟随主题。**文字颜色会依据背景亮度自动调整**，保证可读 |
| **标题字体 / 正文字体** | 下拉框列出系统已安装字体，「跟随主题」为默认 |
| **标题栏始终纯白** | 无论皮肤如何，顶部标题栏都用纯白背景 |
| **省内存模式（软件渲染）** | 内存占用约降低 40%，但滚动/拖动可能略慢。**适合硬件较弱的机器** |

> **省内存模式的实测效果**：内存从约 361 MB 降至约 215 MB。
> 改动后应用会**自动重启**以生效，无需手工操作。

### 启动行为

| 选项 | 说明 |
| --- | --- |
| **启动时打开桌面小窗** | 每次启动自动显示小窗 |
| **桌面小窗始终置顶** | 小窗不被其它窗口遮挡 |
| **开机自动启动** | 登录系统后自动启动本应用。Windows 与银河麒麟均支持 |

> 开机自启动在 Windows 上写入当前用户注册表，在麒麟上写入
> `~/.config/autostart/`（XDG 自启动标准），**均不需要管理员权限**。

### 窗口透明度

分别调节**主窗口**与**小窗**的不透明度（50% ~ 100%）。

> 调节的是**整窗**透明度，窗口后面的内容会真正透出来。

### 数据

**导出待办数据**：同时导出两个文件，可**自选保存位置**。

- **JSON** —— 字段完整，适合备份
- **CSV** —— 适合在 Excel / WPS 中查看（已处理中文编码，不会乱码）

### 节假日数据

见下一节。

### 运行日志

| 按钮 | 作用 |
| --- | --- |
| **查看日志内容** | 在应用内直接查看日志，并提供「复制全部」——**反馈问题时用这个** |
| **打开日志位置** | 尝试用文件管理器打开日志所在文件夹 |
| **清空日志** | 删除日志文件（有确认框） |

- GitHub 项目主页：<https://github.com/zerohk/KylinTodo>

## 七、节假日数据导入

### 为什么需要

- **农历与二十四节气**由算法推算，**任何年份都可用，无需联网**
- **法定节假日与调休**是固定数据表（需国务院逐年公布），
  内置数据只覆盖到 **2026-10-10**。超出后日期不再显示「休 / 班」

因此提供导入功能，让你自行补齐后续年份。

### 怎么用

1. 设置 → 节假日数据 → **导出模板**，得到一个 `.xlsx` 文件
2. 用 Excel / WPS 打开填写，三列：

   | 日期 | 类型 | 名称 |
   | --- | --- | --- |
   | 2027-02-06 | 休 | 春节 |
   | 2027-02-13 | 班 | 调休上班 |

   - **日期**支持 `2027-02-06`、`2027/2/6`、`2027年2月6日` 三种写法
   - **类型**填「休」表示放假，「班」表示调休上班
   - **名称**可留空（留空时会自动沿用内置数据的名称）

3. 回到设置点 **导入数据**，选择填好的文件

导入的数据**优先于**内置数据，且重启后仍然生效。可随时点「清空」回退。

> 导入前会逐行校验。有问题的行不会中断整体导入，而是列出
> 「第几行有什么问题」，便于对照修改。模板自带的填写说明行会被自动忽略。

## 八、数据与备份

### 数据存放位置

| 系统 | 位置 |
| --- | --- |
| 银河麒麟 / Linux | `~/.local/share/KylinTodo/` |
| Windows | `%LOCALAPPDATA%\KylinTodo\` |

目录内包含：

- `kylintodo.db` —— 待办数据库（SQLite）
- `logs/app.log` —— 运行日志
- `export/` —— 默认导出目录

### 备份建议

- 退出应用后直接复制整个 `KylinTodo` 目录即可完成备份
- 或使用 设置 → 数据 → 导出待办数据（可导出 JSON 与 CSV）

> 卸载应用**不会**删除该目录，重装后数据自动读回。

## 九、遇到问题怎么办

1. 打开 **设置 → 运行日志 → 查看日志内容**
2. 点 **「复制全部」**
3. 把内容发到 <https://github.com/zerohk/KylinTodo/issues>
   或邮箱 forlovelygirlfyt@gmail.com

日志里已包含版本、运行环境、JVM 内存参数、自启动状态等关键信息，
能大幅加快定位。**准备反馈前建议先点「清空日志」，再复现一次问题** ——
这样日志里就只有该问题的记录。

## 十、常见问题

**Q：节假日不显示了？**

内置节假日数据覆盖到 2026-10-10。之后的日期需要自行导入，见第七节。
农历与节气不受影响，任何年份都正常。

**Q：点图标启动没反应，点几次开了好几个窗口？**

v1.1.1 起已加入单实例守卫，多次点击不会再开出多个窗口。
启动时会先显示启动画面，请稍候几秒。

**Q：内存占用偏高？**

请开启 设置 → 外观 → **省内存模式（软件渲染）**，内存约降低 40%。
应用会自动重启生效。

**Q：窗口的标题栏和以前不一样了？**

v1.1.5 起主窗口改为无边框自绘，因此：

- 拖动**标题栏**可移动窗口
- 拖动**右下角**可调整窗口大小
- 标题栏右侧依次是：置顶 / 最小化 / 关闭
- 好处是可以整窗真透明、标题栏颜色跟随主题

**Q：怎么设置开机自动启动？**

设置 → 启动行为 → 勾选「开机自动启动」。Windows 与银河麒麟均支持。

若登录系统后没有自动启动，请在系统的「开机启动项」/「启动应用程序」
界面确认本应用没有被禁用。

**Q：有键盘快捷键吗？**

目前在待办输入框内按回车可提交，暂无全局快捷键。

**Q：能在 ARM64 的麒麟上装吗？**

目前只提供 x86_64 的安装包。所用底层库（SQLite、农历库）都支持 ARM64，
但尚未构建 ARM64 产物。

## 十一、卸载

**麒麟 / Linux**

```bash
sudo dpkg -r dazhi-calendar
```

**Windows**：在「设置 → 应用」里卸载，或从安装目录运行卸载程序。

卸载不会删除 `~/.local/share/KylinTodo/` 中的数据。若想彻底清除，
手动删除该目录即可。
